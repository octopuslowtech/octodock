# Mascot assets

`octopus-directions.webp` (nine gaze directions) and `octopus-reactions.webp`
(nine expressions) are 3x3 sprite sheets embedded into the native application at
compile time. Both are drawn by `scripts/draw-octopus-mascot.py <this folder>`.

The sheet layout and the mascot's behaviour follow
[`nilbuild/page-mascot`](https://github.com/nilbuild/page-mascot) (MIT); its
license is retained beside the assets in `LICENSE.page-mascot`.
